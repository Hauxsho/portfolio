## Overview

This repository hosts the source code for my professional portfolio. This site is built from the ground up for **Backend, Distributed Systems, and Fintech Engineering**.

It emphasizes **architecture specifications, failure mode resilience, and trade-off analysis** over superficial UI demos, presenting system design execution topologies and production platform case studies.

- **Interactive Architecture Modals:** Two-tab technical deep dives for each system covering *Architecture Specs & Trade-offs* and *Execution Topologies (SVG data flow diagrams)*.

- **Zero-Dependency Vector Topologies:** Handcrafted SVG execution flow graphs that demonstrate event transitions, message brokers, and persistence layers.
